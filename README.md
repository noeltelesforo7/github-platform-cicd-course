# GitHub Platform CI/CD Course

Repositorio de aprendizaje práctico para dominar GitHub como plataforma y GitHub Actions para integraciones CI/CD.

## Objetivo

Este repositorio está diseñado para aprender paso a paso:

- Fundamentos de GitHub
- Trabajo colaborativo con ramas y pull requests
- Gestión del trabajo con issues y projects
- Automatización con GitHub Actions
- Integraciones CI
- Despliegues CD
- Seguridad y mejores prácticas
- Reutilización de workflows
- Releases, debugging y observabilidad

## Estructura del repositorio

- `modules/`: módulos del curso
- `shared/`: recursos compartidos
- `ROADMAP.md`: ruta de aprendizaje recomendada
- `CONTRIBUTING.md`: guía para contribuir o extender el contenido

## Metodología

Cada módulo incluye:

- teoría
- ejemplos
- ejercicios
- checklist de validación

## Ruta recomendada

1. Fundamentos de GitHub
2. Ramas y Pull Requests
3. Issues y Projects
4. GitHub Actions básico
5. CI pipelines
6. Artefactos, cache y matrix
7. CD y environments
8. Seguridad
9. Reutilización
10. Releases
11. Debugging
12. Proyecto final
