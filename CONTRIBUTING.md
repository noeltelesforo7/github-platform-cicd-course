# Contribuir al repositorio

## Objetivo

Este repositorio está organizado por módulos para facilitar el aprendizaje incremental sobre GitHub y GitHub Actions.

## Estructura esperada de cada módulo

Cada módulo debe incluir:

- `README.md`
- `theory.md`
- `examples/`
- `exercises/`
- `checklist.md`

## Convenciones

- Usar nombres claros y consistentes
- Mantener los ejemplos simples antes de hacer versiones avanzadas
- Separar teoría de ejercicios
- Documentar el objetivo de cada archivo

## Buenas prácticas al contribuir

- Hacer cambios pequeños y enfocados
- Usar mensajes de commit claros
- Mantener la estructura común entre módulos
- Evitar mezclar teoría, ejemplos y soluciones en un mismo archivo
