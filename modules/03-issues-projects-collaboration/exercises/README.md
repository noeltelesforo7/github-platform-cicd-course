# Ejercicios - Módulo 3

## Ejercicio 1: Explorar la pestaña Issues
Entra a la pestaña `Issues` del repositorio e identifica para qué sirve.

## Ejercicio 2: Crear un issue
Crea un issue nuevo con un título claro y una descripción breve. Puede ser algo como:

- mejorar el README principal
- agregar más ejercicios al módulo 3
- crear una plantilla de pull request

## Ejercicio 3: Agregar labels
Si tu repositorio lo permite, asigna una o más labels al issue creado. Por ejemplo:

- `documentation`
- `enhancement`

## Ejercicio 4: Revisar el estado del issue
Observa cómo GitHub muestra el issue como abierto y cómo se registran sus metadatos.

## Ejercicio 5: Cerrar un issue manualmente
Cierra el issue y verifica cómo cambia su estado.

## Ejercicio 6: Explorar la pestaña Projects
Entra a la pestaña `Projects` y revisa si puedes crear un proyecto o tablero.

## Ejercicio 7: Relacionar trabajo
Explica con tus propias palabras cómo se relacionan:
- un issue
- una rama
- un pull request
- un merge
