# Módulo 3: Issues, Projects y colaboración

## Objetivo

Aprender a gestionar trabajo en GitHub usando issues, labels y projects para organizar tareas, dar seguimiento y mejorar la colaboración.

## Resultados esperados

Al finalizar este módulo podrás:

- entender qué es un issue
- crear issues para registrar tareas, errores o mejoras
- diferenciar issues de pull requests
- comprender para qué sirven labels y milestones
- entender cómo usar GitHub Projects para organizar trabajo
- relacionar issues con ramas y pull requests

- `theory.md`: contenido teórico
- `examples/`: ejemplos básicos
- `exercises/`: ejercicios prácticos
