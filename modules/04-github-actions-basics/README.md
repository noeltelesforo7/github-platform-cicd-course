# Módulo 4: GitHub Actions desde cero

## Objetivo

Aprender qué es GitHub Actions y cómo crear workflows básicos para automatizar tareas dentro de un repositorio.

## Resultados esperados

Al finalizar este módulo podrás:

- entender qué es GitHub Actions
- identificar qué es un workflow
- comprender la diferencia entre jobs y steps
- reconocer eventos comunes que disparan workflows
- crear un workflow básico en el repositorio
- revisar ejecuciones desde la pestaña Actions

## Archivos del módulo

- `theory.md`: contenido teórico
- `examples/`: ejemplos básicos
- `exercises/`: ejercicios prácticos
- `checklist.md`: lista de verificación del módulo
