# Ejercicios - Módulo 4

## Ejercicio 1: Explorar la pestaña Actions
Entra a la pestaña `Actions` del repositorio e identifica para qué sirve.

## Ejercicio 2: Crear la carpeta de workflows
Crea la ruta `.github/workflows/` dentro del repositorio.

## Ejercicio 3: Crear un workflow básico
Crea un archivo llamado `hello.yml` dentro de `.github/workflows/`.

## Ejercicio 4: Definir una ejecución manual
Configura el workflow para que pueda ejecutarse con `workflow_dispatch`.

## Ejercicio 5: Agregar un job y un step
Haz que el workflow ejecute un mensaje simple en consola usando `echo`.

## Ejercicio 6: Ejecutar el workflow
Lanza manualmente el workflow desde la pestaña `Actions`.

## Ejercicio 7: Revisar la ejecución
Entra a la ejecución y revisa:

- nombre del workflow
- job ejecutado
- step ejecutado
- logs generados

## Ejercicio 8: Explicar el flujo
Describe con tus propias palabras qué hace el workflow desde que se dispara hasta que termina.
