# Módulo 5: CI pipelines con Node.js

## Objetivo

Aprender a construir un pipeline de integración continua con GitHub Actions para una aplicación Node.js, ejecutando instalación de dependencias, lint, tests y build.

## Resultados esperados

Al finalizar este módulo podrás:

- entender qué es un pipeline de CI
- crear una aplicación Node.js mínima para practicar
- definir scripts de `lint`, `test` y `build`
- crear un workflow que se ejecute en `push` y `pull_request`
- revisar el resultado del pipeline en GitHub Actions
- entender la relación entre PRs y validaciones automáticas

## Archivos del módulo

- `theory.md`: contenido teórico
- `examples/`: ejemplos básicos
- `exercises/`: ejercicios prácticos
