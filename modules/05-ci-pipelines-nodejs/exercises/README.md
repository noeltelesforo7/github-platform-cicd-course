# Ejercicios - Módulo 5

## Ejercicio 1: Crear una aplicación Node.js mínima
Agregar una carpeta para una app de ejemplo dentro del repositorio.

## Ejercicio 2: Crear un `package.json`
Definir un proyecto Node.js con scripts básicos.

## Ejercicio 3: Agregar scripts de validación
Incluir scripts para:

- `lint`
- `test`
- `build`

## Ejercicio 4: Crear el workflow de CI
Agregar un workflow dentro de `.github/workflows/` para ejecutar el pipeline.

## Ejercicio 5: Configurar eventos
Hacer que el workflow se dispare en:

- `push`
- `pull_request`

## Ejercicio 6: Instalar dependencias en el pipeline
Usar pasos para preparar Node.js e instalar dependencias.

## Ejercicio 7: Ejecutar lint, test y build
Hacer que el workflow ejecute los scripts definidos en `package.json`.

## Ejercicio 8: Revisar la ejecución
Entrar a la pestaña `Actions` y analizar el resultado del pipeline.

## Ejercicio 9: Probar un cambio
Realizar una modificación en la app o en los scripts y observar cómo responde el pipeline.
