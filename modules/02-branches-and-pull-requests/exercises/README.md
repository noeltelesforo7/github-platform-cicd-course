# Ejercicios - Módulo 2

## Ejercicio 1: Identificar la rama actual
Entra al repositorio y localiza el selector de ramas para identificar en qué rama estás trabajando.

## Ejercicio 2: Explorar las ramas existentes
Revisa si el repositorio tiene más de una rama y observa cómo GitHub las muestra.

## Ejercicio 3: Crear una nueva rama
Crea una rama nueva con un nombre descriptivo, por ejemplo:

- `docs/module-2-update`
- `feature/module-2-content`

## Ejercicio 4: Editar un archivo desde la nueva rama
Desde la rama creada, modifica alguno de los archivos del Módulo 2 y guarda el cambio con un commit.

## Ejercicio 5: Abrir un Pull Request
Abre un pull request desde tu nueva rama hacia `main`.

## Ejercicio 6: Revisar el Pull Request
Dentro del PR, identifica estos elementos:

- título
- descripción
- rama de origen
- rama de destino
- commits
- archivos modificados

## Ejercicio 7: Hacer merge del Pull Request
Si todo está correcto, integra el pull request hacia `main`.

## Ejercicio 8: Confirmar el cambio integrado
Vuelve a la rama `main` y verifica que el cambio aparezca reflejado en el archivo correspondiente.
