# Módulo 2: Ramas y Pull Requests

## Objetivo

Aprender a trabajar con ramas y pull requests para proponer, revisar e integrar cambios de forma ordenada en GitHub.

## Resultados esperados

Al finalizar este módulo podrás:

- entender para qué sirve una rama
- crear ramas para cambios específicos
- comprender qué es un pull request
- identificar las partes principales de un pull request
- entender cómo se revisan e integran cambios en GitHub

## Archivos del módulo

- `theory.md`: contenido teórico
- `examples/`: ejemplos básicos
- `exercises/`: ejercicios prácticos
- `checklist.md`: lista de verificación del módulo

## Nota práctica

Este módulo se está utilizando para practicar el flujo de ramas y pull requests directamente en GitHub.
