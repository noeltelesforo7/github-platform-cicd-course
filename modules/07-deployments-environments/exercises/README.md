# Ejercicios - Módulo 7

## Ejercicio 1: Explorar la sección Environments
Entra a la configuración del repositorio y ubica la sección `Environments`.

## Ejercicio 2: Crear un environment de staging
Crea un environment llamado `staging`.

## Ejercicio 3: Crear un environment de production
Crea un environment llamado `production`.

## Ejercicio 4: Proteger production
Configura una regla básica de aprobación manual para `production`, si tu plan de GitHub lo permite.

## Ejercicio 5: Crear un workflow de despliegue a staging
Define un workflow simple que se ejecute después de un `push` a `main` y use el environment `staging`.

## Ejercicio 6: Crear un workflow manual de despliegue a production
Define un workflow con `workflow_dispatch` para desplegar manualmente a `production`.

## Ejercicio 7: Revisar la ejecución
Observa cómo GitHub muestra el uso del environment durante la ejecución del workflow.

## Ejercicio 8: Explicar el flujo
Describe con tus propias palabras cómo se conecta CI con un despliegue a staging y luego a producción.
