# Módulo 7: Deployments y environments

## Objetivo

Aprender a diseñar flujos básicos de entrega continua en GitHub Actions usando deployments y environments para separar entornos, controlar despliegues y aplicar aprobaciones.

## Resultados esperados

Al finalizar este módulo podrás:

- entender qué es CD
- entender qué es un deployment
- comprender qué es un environment en GitHub
- diferenciar staging y production
- crear un workflow de despliegue básico
- usar approvals manuales en un environment protegido
- entender cómo conectar CI con CD
