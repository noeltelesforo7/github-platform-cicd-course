# Ejercicios - Módulo 6

## Ejercicio 1: Identificar oportunidades de mejora
Revisa el workflow actual de CI y explica qué partes podrían optimizarse o ampliarse.

## Ejercicio 2: Agregar cache
Configura el workflow para reutilizar dependencias de Node.js entre ejecuciones.

## Ejercicio 3: Probar el efecto del cache
Ejecuta el pipeline más de una vez y observa si mejora el tiempo de instalación.

## Ejercicio 4: Crear un artefacto simple
Genera un archivo de salida en el proceso de build y súbelo como artefacto.

## Ejercicio 5: Descargar y revisar el artefacto
Desde la ejecución en GitHub Actions, localiza y descarga el artefacto generado.

## Ejercicio 6: Agregar matrix strategy
Haz que el pipeline se ejecute al menos en dos versiones de Node.js.

## Ejercicio 7: Revisar ejecuciones paralelas
Observa cómo GitHub muestra múltiples ejecuciones del mismo job bajo la matrix.

## Ejercicio 8: Comparar resultados
Explica qué diferencia hay entre:
- usar cache
- subir artefactos
- ejecutar matrix
