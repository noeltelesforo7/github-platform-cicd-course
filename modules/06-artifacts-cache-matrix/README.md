# Módulo 6: Artefactos, cache y matrix

## Objetivo

Aprender a mejorar pipelines de CI en GitHub Actions usando cache para acelerar ejecuciones, artefactos para conservar resultados y matrix strategy para validar en múltiples versiones.

## Resultados esperados

Al finalizar este módulo podrás:

- entender qué es cache en GitHub Actions
- entender qué es un artefacto
- comprender qué es una matrix strategy
- ejecutar un workflow en varias versiones de Node.js
- guardar archivos generados como artefactos
- identificar oportunidades de optimización en CI

## Archivos del módulo

- `theory.md`: contenido teórico
- `examples/`: ejemplos básicos
- `exercises/`: ejercicios prácticos
