# Ejercicios - Módulo 1

## Ejercicio 1: Crear el repositorio
Crea un repositorio nuevo en GitHub y agrega un archivo `README.md`.

## Ejercicio 2: Explorar la interfaz del repositorio
Ubica e identifica estas pestañas en GitHub:

- Code
- Issues
- Pull requests
- Actions
- Projects
- Settings

## Ejercicio 3: Editar un archivo desde GitHub web
Edita el `README.md` principal del repositorio y realiza un commit desde la interfaz web.

## Ejercicio 4: Crear la estructura del módulo
Crea dentro del repositorio la carpeta `modules/01-github-fundamentals/` con sus archivos base.

## Ejercicio 5: Revisar el historial
Explora la sección de commits del repositorio y revisa los cambios realizados hasta ahora.

## Ejercicio 6: Identificar conceptos
Explica con tus propias palabras:

- qué es Git
- qué es GitHub
- qué es un repositorio
- qué es un commit
- qué es una rama
- qué es un pull request
