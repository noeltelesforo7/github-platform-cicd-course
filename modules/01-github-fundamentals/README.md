# Módulo 1: Fundamentos de GitHub

## Objetivo

Comprender qué es GitHub, cómo se organiza el trabajo en repositorios y cuál es el flujo básico para colaborar usando Git.

## Resultados esperados

Al finalizar este módulo podrás:

- entender la diferencia entre Git y GitHub
- crear y clonar repositorios
- hacer cambios y subir commits
- trabajar con ramas básicas
- entender el flujo general de colaboración

## Archivos del módulo

- `theory.md`: contenido teórico
- `examples/`: ejemplos básicos
- `exercises/`: ejercicios prácticos
- `checklist.md`: lista de verificación del módulo
